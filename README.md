- [Syllabus](SYLLABUS.md)

Lancer les slides avec `python3 scripts/serve.py`, puis ouvrir `http://127.0.0.1:8000/`.
Lancer le serveur fictif dans un autre terminal avec `python3 server/app.py --demo`.

Pour le TP J2, il faut Node.js 20+, une clé OpenRouter, un modèle gratuit compatible avec les appels d'outils et la clé d'équipe transmise par le formateur. Gardez les clés hors du dépôt et de la page web.
